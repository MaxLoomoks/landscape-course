САЙТ «ЛАНДШАФТНЫЙ ДИЗАЙН ДЛЯ 10 СОТОК»
Публикация через GitHub Pages без токена

СОСТАВ
- index.html — главная страница сайта
- assets/ — шесть изображений обложек модулей
- .nojekyll — отключает обработку Jekyll для статических файлов

ПУБЛИКАЦИЯ
1. Откройте https://github.com и войдите в свой аккаунт.
2. Нажмите New repository.
3. Название, например: landscape-course
4. Выберите Public и нажмите Create repository.
5. На странице репозитория выберите Add file -> Upload files.
6. Распакуйте этот ZIP на компьютере.
7. Перетащите СОДЕРЖИМОЕ папки landscape-course-site-ready в окно GitHub:
   index.html, папку assets, .nojekyll и README.txt.
   Важно: index.html должен находиться в корне репозитория, не во вложенной папке.
8. Нажмите Commit changes.
9. Откройте Settings -> Pages.
10. В разделе Build and deployment выберите:
    Source: Deploy from a branch
    Branch: main
    Folder: / (root)
11. Нажмите Save и подождите завершения публикации.
12. Адрес сайта будет иметь вид:
    https://ВАШ-ЛОГИН.github.io/НАЗВАНИЕ-РЕПОЗИТОРИЯ/

ПРОВЕРКА
- Откройте адрес GitHub Pages после появления сообщения о публикации.
- Проверьте, что видны обложки всех модулей и переходы по разделам работают.
- Если отображается 404, проверьте, что index.html загружен в корень репозитория и Pages настроен на main / root.

ВАЖНО ПЕРЕД ПУБЛИКАЦИЕЙ
- PDF-файлы курса в архив не входят. Сейчас сайт показывает описание курса и обложки.
- В HTML указаны черновые цены с пометкой о согласовании.
- Кнопки тарифов ведут к разделу «Вопросы»; оплата и автоматическая выдача материалов не подключены.
- Контактная кнопка ведёт в Telegram: https://t.me/ogorodru
- Для публикации этим способом GitHub-токен не требуется. Не отправляйте пароли и токены в чат.

ОБНОВЛЕНИЕ
Для изменения сайта отредактируйте нужные файлы локально и снова загрузите их в репозиторий через Add file -> Upload files, подтвердив замену существующих файлов.
